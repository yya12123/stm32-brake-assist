## 一、为什么要分阶段（重要）

一次性画 30 个元件，一旦不亮你根本不知道是线接错、固件时钟错、还是模型没跑。
所以分 3 步，每步都能看到东西动：

| 阶段 | 内容 | 元件数 | 能验证什么 |
|---|---|---|---|
| **① 最小系统** | 芯片 + 电源 + 晶振 + 复位 + 1 个 LED | 8 | 固件能不能跑、时钟对不对 |
| **② 输入输出** | 电位器 + 刹车灯 + 双闪 + 蜂鸣 + 继电器 | 12 | 核心逻辑通不通 |
| **③ 超声波 + 串口** | HCSR04 + 虚拟终端 | 3 | 测距与数据上报 |

## 二、阶段①：最小系统（先跑起来）

### 取元件
| 搜索词 | 数量 | 属性 |
|---|---|---|
| `STM32F103C8` | 1 | Program File = fw.hex，Clock Frequency = 8MHz |
| `CRYSTAL` | 1 | Frequency = 8M |
| `CAP` | 3 | 2 个改 22pF，1 个改 100nF |
| `RES` | 2 | 10k ×1（复位上拉）、10k ×1（BOOT0 下拉） |
| `LED_5_Green` | 1 | 运行灯 |
| `RES` | 1 | 330Ω |
| `POWER`/`GROUND` | 若干 | Terminals Mode |

### 接线
| 引脚 | 接 |
|---|---|
| VDD(24/36/48)、VDDA(9) | **+3.3V** |
| VSS(23/35/47)、VSSA(8) | **GND** |
| NRST(7) | 10k → +3.3V，100nF → GND |
| OSC_IN(5) | 晶振 1 脚 + 22pF → GND |
| OSC_OUT(6) | 晶振 2 脚 + 22pF → GND |
| BOOT0(44) | 10k → GND |
| **PC13(2)** | **→ 330Ω → LED_5_Green → +3.3V**（低电平点亮） |

> 电源：Design → Configure Power Rails，VDD = 3.3V。

### 运行
点 ▶ Play。**绿灯每 0.5 秒闪一次 = 固件跑起来了，时钟正确。**

- 不闪 → 换 `fw_8mhz.hex` 再试（PLL 没被模拟）
- 还是不闪 → 检查 Program File 路径、BOOT0 是否接地

## 三、阶段②：输入输出

### 追加元件
| 搜索词 | 数量 | 用途 |
|---|---|---|
| `POT-HG` | 2 | 踏板 + 减速度 |
| `LED_5_Red` | 3 | 刹车灯 ×2、助力泵指示 ×1 |
| `LED_5_Yellow` | 2 | 左/右转向 |
| `BUZZER` | 1 | 报警 |
| `G5C-1-DC5` | 1 | 继电器 |
| `2N2222` | 1 | 驱动继电器 |
| `1N4007` | 1 | 续流 |
| `RES` | 6 | 220Ω×4、1kΩ×1、10kΩ×1 |

### 接线
| 功能 | 接线 |
|---|---|
| 踏板电位器 | 上→+3.3V，下→GND，中→**PA0(10)** |
| 减速度电位器 | 上→+3.3V，下→GND，中→**PA1(11)** |
| 刹车灯 | **PB6(42)** → 220Ω → 红灯 → GND |
| 左转向 | **PB7(43)** → 220Ω → 黄灯 → GND |
| 右转向 | **PB8(45)** → 220Ω → 黄灯 → GND |
| 蜂鸣器 | **PB5(41)** → BUZZER → GND |
| 继电器 | **PC14(3)** → 1k → 2N2222 基极；E→GND；C→线圈；线圈另一端→+5V；1N4007 反并线圈 |
| 助力泵指示 | 触点：+5V → 220Ω → 红灯 → GND |

> 继电器线圈要 **+5V**（另一路电源轨 VCC），其余都在 3.3V 上。

### 验证
1. 调踏板电位器（选中后按 ↑/↓）→ 刹车灯亮度分 3 级变化
2. 猛调踏板 + 把减速度电位器调高 → 左右黄灯 1Hz 双闪、蜂鸣器响、继电器"咔哒"

## 四、阶段③：超声波 + 串口

| 元件 | 接线 |
|---|---|
| `HCSR04` | VCC→+5V，GND→GND，**TRIG→PB0(18)**，**ECHO→PB1(19)** |
| `VIRTUAL TERMINAL`（Virtual Instruments Mode） | RXD→**PA2(12)**，TXD→**PA3(13)**，Baud=9600 |

双击 HCSR04，把距离属性改成 30cm → 黄灯闪；改成 20cm → 急促闪 + 蜂鸣。

终端每秒打印 10 行 `P=.. R=.. D=.. V=.. S=..`。

## 五、排错表

| 现象 | 处理 |
|---|---|
| 全黑不跑 | 换 8MHz hex；检查 Program File 和 BOOT0 |
| 串口乱码 | Clock Frequency 与 hex 版本要匹配（8M↔8M，72M↔72M） |
| LED 不亮 | 极性反了；PC13 是低电平点亮 |
| 继电器不吸 | 2N2222 引脚是 E-B-C，别接反 |
| 超声读不到 | TRIG/ECHO 反了；HCSR04 的 VCC 必须 5V |
