# 配图截图清单（4 张）

## 怎么截（关键）

1. **先点一下 Proteus 窗口**（让它成为当前活动窗口）
2. 按 **Alt + Print Screen** —— 只截当前窗口，不会带上浏览器和任务栏
3. 直接粘贴发我，或存成 PNG

> 不要用全屏截图，会有半个浏览器在里面。
> 一张图至少截 **2~3 次**，挑灯亮着的那张发我。

## 必须出现在画面里的东西

- 整块原理图（MCU + 灯 + 超声波 + 风扇）
- **虚拟终端窗口**（显示 P/V/S 数据，这是状态证据）
- 状态栏（能看出仿真在运行）

## 四张图分别对应

| 图号 | 状态 | 怎么制造 | 画面要体现 |
|---|---|---|---|
| **图 5-1** | 正常 S=0 | 距离 200cm，踏板松开 | 黄灯全灭，终端 S=0 |
| **图 5-2** | 跟车预警 S=1 | 距离调到 **120cm** | 左右黄灯**亮着**，终端 S=1 |
| **图 5-3** | 危险预警 S=2 | 距离调到 **30cm** | 左右黄灯**亮着**，终端 S=2 |
| **图 5-4** | 急刹辅助 S=3 | 距离 200cm，D≈80，猛拧踏板 | 双闪亮、终端 S=3，最好能看到风扇转起来 |

## 抓闪烁状态的技巧

黄灯在闪，截图时可能刚好是灭的。两种办法：

**办法一（推荐）**：看到灯亮，立刻点 **⏸ 暂停**，画面定格后再截图。最稳。

**办法二**：连续按几次 Alt+PrintScreen，总有一张是亮的。
