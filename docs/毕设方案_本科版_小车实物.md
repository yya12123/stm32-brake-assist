## 二、系统设计

```
        ┌──────────── 感知层 ────────────┐
踏板电位器 B10K ──ADC──┐
电池电压 分压 ───ADC──┤
HC-SR04(舵机云台) ────┤   ┌──────────┐   ┌──────── 执行层 ────────┐
MPU6050(减速度) ─I2C──┼──►│STM32F103 │──►│ TB6612 → 左右电机       │
码盘×2 ─────EXTI─────┤   │  C8T6    │──►│ 刹车灯 PWM(红) 分级     │
                       │   └──────────┘   │ 左/右转向灯(黄) 双闪    │
                       │        │         │ 继电器(模拟助力泵)      │
                       │        ├─I2C──► OLED 0.96                │
                       │        ├─UART─► CH340 → 上位机曲线       │
                       │        └─GPIO─► 蜂鸣器                   │
```

### 引脚分配（已避让冲突，可直接照抄）

| 功能 | 引脚 | 外设/模式 |
|---|---|---|
| 制动踏板 | PA0 | ADC1_IN0（模拟输入） |
| 电池电压检测 | PA1 | ADC1_IN1（分压 1/2） |
| 调试串口 | PA2 / PA3 | USART2 TX/RX → CH340 |
| 左码盘 | PB9 | EXTI9 上升沿计数 |
| 右码盘 | PA10 | EXTI10 上升沿计数 |
| 左电机 PWM | PA8 | TIM1_CH1 |
| 右电机 PWM | PA11 | TIM1_CH4 |
| 左电机方向 | PB12 / PB13 | GPIO（AIN1/AIN2） |
| 右电机方向 | PB14 / PB15 | GPIO（BIN1/BIN2） |
| 超声波 Trig | PB0 | GPIO 推挽 |
| 超声波 Echo | PB1 | EXTI1 + TIM2 计 μs |
| 舵机 | PA6 | TIM3_CH1（50Hz） |
| 刹车灯 | PB6 | TIM4_CH1 PWM |
| 左转向灯 | PB7 | GPIO |
| 右转向灯 | PB8 | GPIO |
| 蜂鸣器 | PB5 | GPIO |
| OLED + MPU6050 | PB10 / PB11 | I2C2（0x3C / 0x68，不冲突） |
| 继电器 | PC14 | GPIO |
| 运行灯 | PC13 | 板载 LED |

> TB6612 的 STBY 直接接 3.3V，省一个引脚。

### 功能清单

**基础（必须做，论文正文主体）**
1. 踏板行程 ADC 采集 + 滑动平均滤波 → 0~100%
2. 制动强度三级识别 → 刹车灯 PWM 30/60/100% 分级
3. 紧急制动双阈值判断（踏板变化率 + MPU6050 减速度）→ 自动双闪 + 蜂鸣 + 继电器吸合
4. 超声波跟车测距：>3m 正常 / 1.5~3m 黄灯慢闪 / <1.5m 急闪+蜂鸣
5. 车速采集（码盘）+ OLED 实时显示
6. 串口上传数据 → 上位机画曲线（**论文图表数据来源**）

**加分（时间够就做，答辩能拉开差距）**
7. 舵机云台扫描，画出"距离-角度"极坐标图
8. 电池电压监测 + 低电报警
9. 参数在线标定（串口命令改阈值，不用重烧程序）
10. 蓝牙 HC-05 手机监控（+¥15）

## 六、风险与规避（这些坑我提前踩过）

| 风险 | 现象 | 规避 |
|---|---|---|
| 电机干扰 | 一开电机 ADC 乱跳、超声乱码 | 电机电源与主控电源分开走线、各并联 100nF+10μF、ADC 滑动平均、超声连续 3 次取中值 |
| 5V 打 3.3V | HC-SR04 Echo 直连 PB1 烧脚 | 1k+2k 分压（PB0/PB1 不是 5V 容忍引脚） |
| 电池压降 | 电机启动瞬间主控复位 | 7.4V→LM2596→5V→AMS1117→3.3V，加 470μF 大电容 |
| TB6612 过热 | 堵转烧模块 | 别堵转、加 100nF 去耦、限 PWM |
| Proteus 没模型 | 打开找不到 STM32 | **必须 Proteus 8.15 以上**；HC-SR04 老版本用自带 SRF04 替代 |
| 仿真≠实物 | 答辩被问"为什么仿真能跑实物不行" | 论文里单列一节说明差异（仿真用 L298 模型，实物用 TB6612） |
| 查重超 30% | 取消答辩资格 | 论文全部自己改写；引用规范标注 |
