# 阶段① 手把手接线（照做即可）

> 目标：让板子上的绿灯每 0.5 秒闪一次 —— 证明固件能跑、时钟对。
> 预计 10 分钟。全程只需要 **3 个元件 + 3 根线**。

---

## 第 0 步：清理我留下的东西

画布上这几样是我操作时多放的，先删掉：

| 名称 | 位置 | 操作 |
|---|---|---|
| **U3**（第二块 BLUEPILL） | 右下角 | 左键点它 → 按键盘 `Delete` |
| **D2**（LED-GREEN） | 最下面 | 左键点它 → 按 `Delete` |

> **U2（BLUEPILL）留着**，就是我们要用的这块。
> 你原来摆的 U1、C1、C2、C3、X1、D1、R3、R2 全部不用管，放着就行，不影响仿真。

---

## 第 1 步：放 3 个元件

### 1.1 打开元件库

按键盘 **P** → 弹出 Pick Devices 对话框。

### 1.2 放 BLUEPILL（如果 U2 已经在了就跳过）

1. Keywords 框输入 `BLUEPILL`
2. 结果列表里双击 `BLUEPILL` 那一行（Library 列显示 BluePill）
3. 对话框关闭后，鼠标在画布空白处**点一下**，元件就放下了
4. 放好后按 **Esc** 退出放置模式（不按的话下一次点击会再放一个）

### 1.3 放发光二极管

1. 再按 **P**，输入 `LED_5_Green`
2. 双击结果 → 在画布空白处点一下放下 → 按 **Esc**

### 1.4 放电阻

1. 按 **P**，输入 `RES`
2. 双击结果 → 画布点一下放下 → 按 **Esc**

### 1.5 放电源端子

1. 左侧工具栏找到 **TERMINALS**（图标是一个带圆点的方框，在 DEVICES 下面一格）
2. 点开后选 **POWER**，在画布上点一下放下
3. 再按 **Esc**

> 放完后画布上应该多出：1 个蓝色小板子（BLUEPILL）、1 个发光二极管、1 个长方形电阻、1 个 POWER 端子。

---

## 第 2 步：改 3 个属性

### 2.1 电阻改 330Ω
双击那个长方形电阻 → 弹出 Edit Component → 把 **Value** 从 `10k` 改成 `330` → 点 **OK**。

### 2.2 电源改成 3.3V 轨
双击 POWER 端子 → 把 **String** 改成 `VDD` → OK。

### 2.3 板子加载固件（最关键）

双击 **U2（BLUEPILL）** → Edit Component 窗口里有两个属性：

| 属性 | 填什么 |
|---|---|
| **Program File** | 点右边的小文件夹按钮，选 `C:\temp\fw.hex` |
| **Clock Frequency** | `8MHz`（默认一般就是 8MHz，确认一下） |

> 我把 hex 复制到了 `C:\temp\fw.hex`（纯英文路径，避免中文路径出问题）。
> 如果 8MHz 版跑不起来，换成 `C:\temp\fw_8mhz.hex`。

点 **OK**。

---

## 第 3 步：接 3 根线

### 3.1 先认识电感引脚方向

LED 符号：**三角形尖端指向横杠** = 电流从三角形底边流向横杠。
- **三角形底边** = 阳极（正极）
- **横杠那头** = 阴极（负极）

如果方向不对：**点中 LED → 按小键盘 `+` 旋转 90°**（或点左侧工具栏底部的两个弧形箭头按钮）。

### 3.2 连线的正确手势（这是你先前卡住的地方）

1. 鼠标移到**引脚最末端**（那根伸出来的短线头），引脚会变红/出现小方点
2. **点一下**（不要拖）
3. 移动鼠标 —— 会有一条绿线跟着走
4. 移到目标引脚末端，**再点一下**
5. 线就画好了。画错了按 `Esc` 或右键取消

### 3.3 三根线

```
        ┌──────────────┐
        │   VDD (3.3V)  │   ← POWER 端子
        └──────┬───────┘
               │  ①
               ▼
           ┌───────┐
           │  LED  │   阳极朝上（三角形底边）
           │   ▼   │
           └───┬───┘
               │  ②
           ┌───┴───┐
           │ 330Ω  │
           └───┬───┘
               │  ③
        ┌──────┴──────┐
        │   PC13      │   ← BLUEPILL 右侧那根
        │  BLUEPILL   │
        └─────────────┘
```

| 线 | 从 | 到 |
|---|---|---|
| ① | POWER 端子的引脚 | LED **阳极**（三角形底边那头） |
| ② | LED **阴极**（横杠那头） | 电阻一端 |
| ③ | 电阻另一端 | BLUEPILL 右侧的 **PC13** 引脚 |

> PC13 在板子符号的**右侧，靠下位置**，引脚标签写着 `PC13`。

---

## 第 4 步：确认电源轨

1. 顶部菜单 → **设计(N)** → **配置电源轨（Configure Power Rails）**
2. 找到 `VDD` 那一行，把值改成 **3.3V**
3. 确定

---

## 第 5 步：运行

点左下角的 **▶ 播放按钮**（或按 `F12`）。

### 判定标准

| 现象 | 结论 | 下一步 |
|---|---|---|
| **绿灯每 0.5 秒闪一次** | ✅ 完全正确，阶段①通过 | 进阶段②（踏板+刹车灯+双闪） |
| 绿灯常亮或常灭 | 时钟或极性不对 | 换 `fw_8mhz.hex` 再试；再不行检查 LED 方向 |
| 一点反应没有 / 报错 | 固件没加载上 | 双击 U2 确认 Program File 路径对不对 |
| 弹出 "No VSM model" 之类提示 | 模型没授权 | 告诉我截图，我来看 |

---

## 卡住时的自检清单

- [ ] U2 的 Program File 是否真的指向 `C:\temp\fw.hex`
- [ ] Clock Frequency 是否 8MHz
- [ ] LED 阳极是否朝向 3.3V
- [ ] 电源轨 VDD 是否改成 3.3V
- [ ] 三根线是否都点到了引脚末端（悬停变红才算点中）

---

## 为什么这一步值得单独做

后面要接踏板、超声波、刹车灯、双闪、蜂鸣器、继电器 —— 那 20 多根线里只要错一根，现象都是"不动"。
先把**最小回路**跑通，等于先把"固件没问题、时钟没问题"这两个变量排除掉，后面出问题就只可能是接线错了。
