# 毕设评估：STM32 电动汽车刹车辅助与灯光预警控制系统

> 依据：豆包分享链接里的方案（Proteus 仿真 + STM32F103 + 电位器/HC-SR04/LED/继电器）
> 评估日期：2026-11-15

---

## 一、这个毕设到底是什么

一句话：**用 Proteus 画一块 STM32 仿真电路，编个程序让"刹车灯"按踩踏深度变亮、紧急制动时双闪、跟车太近时闪灯报警。**

技术栈很轻：STM32F103 + ADC（读踏板电位器）+ PWM（调刹车灯亮度）+ 输入捕获（超声回波/车速脉冲）+ GPIO（LED/继电器）。
属于"单片机课设"级别的难度，不是"研究型"课题。

**结论先行：可行，纯仿真几乎零成本；但豆包给的细节有 5 个坑，照抄会在答辩时被问穿。**

## 二、豆包方案的问题（我逐条核对过）

| # | 问题 | 后果 | 修法 |
|---|------|------|------|
| 1 | 主控写 **STM32F103C6**（32KB Flash / 10KB RAM），论文写的是 **C8T6**（64KB/20KB） | Keil 按 C8 编译出的 hex 超过 C6 的 32KB，Proteus 里放 C6 会跑飞或直接加载失败 | 统一用 **C8T6**（Proteus 8.15+ 有模型），别用 C6 |
| 2 | HC-SR04 的 Echo 是 **5V 输出**，豆包让直接接 PB1 | PB0/PB1 是 ADC 引脚，**不是 5V 容忍**（F103 的 FT 引脚里没有 PB0/PB1），实物直连会打坏引脚 | 实物加 1k+2k 分压，或换 3.3V 版超声波（US-100 也贵，分压最简单） |
| 3 | 车速用 Proteus 的 **SIGNAL 信号发生器** | 能做，但仿真里 10~100Hz 脉冲计时抖动大，演示时数字乱跳很尴尬 | 双保险：加一路电位器当"车速"（软件换算），信号发生器作对照——**答辩时讲"两种信号源都验证过"反而是加分项** |
| 4 | "刹车辅助"= **继电器 + 一个 LED** | 老师一眼看穿"这就是点灯"，问"这算哪门子刹车辅助"直接哑火 | 加 **MPU6050**（¥5.8）测减速度，做"急刹检测→自动双闪+蜂鸣"，才是闭环；实物还能晃一下就触发，演示效果极好 |
| 5 | 全篇**没有显示、没有串口** | 论文的"实验数据表"没地方来，老师问"你怎么知道是 3 米"没法答 | 加 **0.96 OLED**（¥8.9）显示 距离/踏板%/状态，数据直接从屏上抄进论文表格 |

另外两条不算坑但要知道：
- **HC-SR04 不一定在 Proteus 自带库**（8.16+ 才有，老版本只有 SRF04）。SRF04 可以直接设距离属性，实测 25cm→回波 1.45ms 对得上，用来替代完全够。
- Proteus 8.9 及更老**没有 STM32 模型**，必须 **8.15 以上**（8.15 SP0 实测最稳）。豆包说"8.16 以上"是对的。

## 三、我的加固方案（比豆包多花不到 10 块钱，答辩档次差一档）

信号流：
```
B10K 电位器 ──ADC(PA0)──┐
HC-SR04 ─────捕获(PB1)──┤
MPU6050 ─────I2C(PB10/11)┤──► STM32F103C8T6 ──► 刹车灯 PWM(PB6) 红LED×2
蜂鸣器模块 ───GPIO(PB5)──┘                  ──► 双闪/转向(PB7/PB8) 黄LED×2
                                            ──► 继电器模块(PC14) 模拟助力泵
                                            ──► OLED(0.96 I2C)
```
逻辑：踏板深度→分级亮度；踏板速度+减速度双阈值→紧急制动→双闪+蜂鸣+继电器吸合；超声<3m→跟车预警闪烁；OLED 实时显示。

## 六、答辩一定会问的 5 个问题（提前给他背）

1. 为什么用 PWM 调光，不用 DAC？→ 成本/引脚/效率，且 LED 亮度与占空比近似线性。
2. 紧急制动阈值怎么定的？→ 位移变化率 > X %/ms 且 减速度 > 0.4g，两个条件同时满足才触发，防误触。
3. 超声波测距误差多大？为什么？→ 温度影响声速、回波阈值；25cm 实测 1.45ms，对应 340m/s 合理。
4. 输入捕获怎么算速度？→ 捕获两个上升沿计数差 / 72MHz，得周期，频率×系数=车速。
5. 这是"电动汽车"，怎么体现高压系统？→ 答：本设计针对**整车低压控制与信号层**（12V/3.3V），不涉及动力电池与电机控制器；若扩展可加 CAN 总线上报 BMS。

## 七、需要你确认的 3 件事

1. **学历层次**：专科/成教 → 纯仿真完全够；普通本科 → 建议加 B 档实物 + MPU6050；一本/强校 → 纯仿真会被判工作量不足。
2. **学校要不要求实物**：直接决定买 ¥0 还是 ¥60。
3. **截止时间 + 论文题目是否已定**：题目改了器件清单就得重来。
