## 二、两个必须提醒的点

### 1. 答辩现场别用面包板

面包板接触不良是这类答辩的头号事故：**插得好好的，答辩时某根线松了，灯不亮、屏不显示**。

做法：**调试期用面包板，最终成品焊到洞洞板上**（成本 +¥4，多花 2 小时）。洞洞板做出来的东西拍照进论文也体面得多。
如果嫌焊接麻烦，最低限度：把关键的杜邦线（电源、地、I2C）用热熔胶固定，答辩前 30 分钟通电自检。

### 2. 没有小车，实验数据从哪来

这是砍掉小车后唯一需要补的地方。三个来源足够撑满论文第 5 章：

| 数据来源 | 产出图表 |
|---|---|
| Proteus 仿真 | 电路图、PWM 波形、捕获时序图 |
| **串口采集** | 踏板 ADC→占空比曲线、超距-时间曲线、状态机时序 |
| 实物照片 | 台架接线图、OLED 显示界面、灯效分级对比 |

串口采集这条最关键——**上位机一画就是论文的"实验数据图"**，比手抄表格专业十倍。我写个 Python 脚本，插上 USB 自动出图。

## 三、系统构成（台架版本）

```
B10K 电位器 ──ADC(PA0)──┐
HC-SR04 ─────EXTI(PB1)──┤                    ┌─► 刹车灯 PWM(PB6) 红LED×2 分级
MPU6050 ─────I2C(PB10/11)┼──► STM32F103C8T6 ─┼─► 左/右转向灯(PB7/PB8) 双闪
电池电压 ────ADC(PA1)──┘                    ├─► 继电器(PC14) 模拟助力泵
                                             ├─► 蜂鸣器(PB5) 报警
                                             ├─► OLED 0.96 (I2C)
                                             └─► CH340 → 上位机曲线
```

引脚表沿用上一版，去掉电机/码盘/舵机四组，其余不变：

| 功能 | 引脚 | 模式 |
|---|---|---|
| 制动踏板 | PA0 | ADC1_IN0 |
| 电池电压 | PA1 | ADC1_IN1 |
| 串口 | PA2/PA3 | USART2 → CH340 |
| 超声 Trig | PB0 | GPIO 输出 |
| 超声 Echo | PB1 | EXTI1 + TIM2 计时 |
| 刹车灯 | PB6 | TIM4_CH1 PWM |
| 左转灯 | PB7 | GPIO |
| 右转灯 | PB8 | GPIO |
| 蜂鸣器 | PB5 | GPIO |
| OLED + MPU6050 | PB10/PB11 | I2C2（0x3C / 0x68） |
| 继电器 | PC14 | GPIO |
| 运行灯 | PC13 | 板载 |

### 功能清单（答辩演示顺序）

1. 上电 → OLED 亮，显示"系统就绪"
2. 转电位器 → 刹车灯亮度分三级变化，OLED 同步显示踏板百分比
3. 快速猛转（模拟急刹）→ 继电器"啪"一声吸合 + 蜂鸣器响 + 左右灯自动双闪
4. 手掌靠近超声波 → <3m 慢闪，<1.5m 急闪+蜂鸣
5. 串口 → 电脑上实时曲线滚动

> 演示脚本要背熟，5 个动作 90 秒讲完，直接对应论文的 5 个功能点。
