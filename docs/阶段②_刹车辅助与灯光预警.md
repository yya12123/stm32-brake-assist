## ②-0 先接串口（强烈建议，只要 2 根线）

这一步接上后，你能**直接看到数字**，后面判断对错就不用猜了。

### 放元件

1. 按 **P** → 输入 `VIRTUAL TERMINAL` → 双击结果 → 画布点一下 → **Esc**

> 如果搜不到，用左侧工具栏的 **Virtual Instruments Mode**（示波器图标那一栏），里面第一个就是 VIRTUAL TERMINAL。

### 接线

| 从 | 到 |
|---|---|
| PA2（12脚，板子左侧） | 虚拟终端的 **RXD** |
| PA3（13脚） | 虚拟终端的 **TXD** |

### 设置

双击虚拟终端 → **Baud Rate** 填 **9600** → OK。

### 验证

点运行，虚拟终端窗口应该开始刷：

    P=0 R=0 D=0 V=65535 S=0

**出现这行就说明串口通了。** 这是你后面所有调试的眼睛。

## ②-1 踏板电位器 + 刹车灯

### 放元件

| 按 P 搜索 | 数量 | 说明 |
|---|---|---|
| `POT-HG` | 2 | 一个当踏板，一个当减速度（仿真里代替 MPU6050） |
| `LED_5_Red` | 1 | 刹车灯 |
| `RES` | 1 | 改成 220Ω |

### 接线

**电位器**（POT-HG 有 3 个脚）：

| 引脚 | 接到 |
|---|---|
| 一端 | **VDD** |
| 另一端 | **GND** |
| 中间（滑动端） | **PA0（10脚）** ← 踏板 |

第二个电位器接法一样，但中间接 **PA1（11脚）** ← 减速度。

**刹车灯**（注意方向和运行灯相反，这里是"高电平点亮"）：

    PB6(42脚) ──> LED_5_Red 阳极（三角形底边） ──> 阴极 ──> 220Ω ──> GND

| 从 | 到 |
|---|---|
| PB6（42脚） | 红灯阳极 |
| 红灯阴极 | 220Ω 一端 |
| 220Ω 另一端 | GND |

> **方向别反**：PB6 输出高电平时给电流，所以阳极要朝 PB6。
> 和阶段①那颗运行灯刚好相反（那颗是接到 VDD 的，低电平点亮）。

### 验证

1. 运行
2. 看虚拟终端：**P=** 后面的数字应该在 0~100 之间
3. 选中踏板电位器，点它旁边的小箭头（↑↓）或用鼠标滚轮调
4. **P= 数值变化，刹车灯亮度跟着分三级变**

三级表（对照固件逻辑）：

| 踏板 | P= 数值 | 刹车灯 |
|---|---|---|
| 没踩 | 0~4 | 灭 |
| 轻踩 | 5~39 | 暗（25% 占空比） |
| 中踩 | 40~69 | 中（50%） |
| 重踩 | 70~100 | 亮（90%） |

> **重要提醒**：Proteus 里 PWM 调光可能看起来像"闪烁"而不是"变暗"，因为仿真渲染采样跟不上 1kHz。
> 想确认真的在调光，加一个 **OSCILLOSCOPE**（虚拟仪器里）接 PB6，看方波的占空比变化——**这张图直接放进论文第 5 章**。
> 实物板上就是真正的无级调光了。

## ②-2 左右转向灯（双闪）

### 放元件

| 按 P 搜索 | 数量 |
|---|---|
| `LED_5_Yellow` | 2 |
| `RES` | 2（都改 220Ω） |

### 接线

接法同刹车灯（高电平点亮）：

| 从 | 到 |
|---|---|
| **PB7（43脚）** | 左黄灯阳极 → 阴极 → 220Ω → GND |
| **PB8（45脚）** | 右黄灯阳极 → 阴极 → 220Ω → GND |

### 触发双闪的条件

固件里的急刹判据是**双阈值同时满足**：

1. **踏板变化率** ≥ 6（% per 10ms）—— 也就是快速拧电位器
2. **减速度** ≥ 50 —— 第二个电位器调到一半以上

### 验证

1. 把减速度电位器（接 PA1 那个）先调到 **80 左右**（终端里 D= 显示 80）
2. 然后**猛地把踏板电位器拧到底**（快速转）
3. 应该看到：**左右黄灯 1Hz 交替闪、持续 2 秒**

> 如果只调一个没反应——这是**故意的**，双阈值就是防误触的。论文里正好可以写"单阈值容易误触发，双阈值降低误报率"。

## ②-4 继电器（可选，但答辩加分）

模拟"制动助力泵吸合"，这是让老师觉得"像回事"的关键。

### 放元件

| 按 P 搜索 | 数量 | 作用 |
|---|---|---|
| `G5C-1-DC5` | 1 | 5V 继电器 |
| `2N2222` | 1 | 三极管驱动（单片机引脚带不动线圈） |
| `1N4007` | 1 | 续流二极管，保护三极管 |
| `RES` | 2 | 1kΩ + 220Ω |
| `LED_5_Red` | 1 | 助力泵工作指示 |

### 接线

    3.3V/5V ──> 继电器线圈+ ──> 线圈- ──> 2N2222 集电极(C)
                                            │
    PC14(3脚) ──> 1kΩ ──> 2N2222 基极(B)     │
                          2N2222 发射极(E) ── GND

    1N4007 反并联在线圈两端（带横线那头接电源正）

    触点侧：VCC(5V) ──> 220Ω ──> 红灯 ──> GND

> 2N2222 在 Proteus 里的引脚顺序是 **E-B-C**（看符号上标的字母），别接错。

### 验证

急刹触发时，继电器会"吸合"，指示灯亮。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| P= 一直是 0 或 100 | 电位器滑动端没接 PA0 | 检查中间那个脚 |
| P= 乱跳 | 滑动端接到 VDD 或 GND 了 | 中间脚才是信号 |
| 刹车灯不亮 | 极性反了 | 阳极朝 PB6 |
| 灯一直亮不调光 | PB6 接错脚 | 确认是 42 脚 |
| 双闪不触发 | 只满足一个阈值 | 减速度先调高，再猛拧踏板 |
| 终端没输出 | 波特率不是 9600 | 双击终端改 |
