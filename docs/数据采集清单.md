# 实验数据采集清单

> 目标：采 3 组数据，够写满实验记录
> 方法：运行仿真 → 调到指定状态 → 复制终端里 3~5 行数据发我
> 注意：每测完一组按一次 Ctrl+S（这破仿真会崩）

---

## 采集前准备

1. 打开恢复后的工程，确认 U3（SRF04）和线都在
2. 运行，确认终端在刷 `P=.. R=.. D=.. V=.. W=.. S=..`
3. 先把踏板电位器拧到 0、减速度电位器拧到 0
4. 每行数据代表 100ms，**同一个测点复制 3~5 行**就够（能看出稳定性）

---

## 实验一：跟车距离 → 预警状态（核心数据）

把 SRF04 的距离依次调到下面这些值，每个值等 2 秒（让它稳定），复制终端数据：

| 编号 | 设定距离 | 终端 V= | 终端 W= | S= | 灯光现象 |
|---|---|---|---|---|---|
| 1 | 200 cm | | | | |
| 2 | 150 cm | | | | |
| 3 | 120 cm | | | | |
| 4 | 90 cm | | | | |
| 5 | 60 cm | | | | |
| 6 | 40 cm | | | | |
| 7 | 20 cm | | | | |

**观察重点**：
- V= 是否和设定值接近（差个 1~2cm 正常）
- S= 在哪一档开始变化（固件阈值是 150 / 50）
- 150cm 是边界，可能来回跳，多采两行

> 灯的闪烁频率也记一下：慢闪 / 急闪 / 不闪

## 数据怎么发我

不用整理格式，**直接复制粘贴终端里的几行文本**就行，比如：

```
P=16 R=0 D=0 V=120 W=6960 S=1
P=16 R=0 D=0 V=120 W=6959 S=1
P=16 R=0 D=0 V=120 W=6961 S=1
```

按实验编号分段发（"实验一，120cm：…"），我能自动解析。
